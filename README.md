## 🚀 Featured Projects

### 🏥 Secure Hospital Management System
> **Healthcare · HIPAA-Aligned · AWS DevSecOps**

Production-grade secure infrastructure for a hospital management platform built on Amazon EKS.

- ✅ Jenkins pipeline with SAST (SonarQube), SCA (OWASP Dependency-Check), Trivy container scanning
- ✅ Pod Security Admission — no root execution, no privilege escalation, read-only root filesystem
- ✅ AWS Secrets Manager + External Secrets Operator — zero hardcoded credentials in manifests
- ✅ Multi-stage distroless Docker builds — **60% container attack surface reduction**
- ✅ SSL/TLS certificate automation via AWS ACM + ALB Ingress Controller
- ✅ Full WAPT with Burp Suite — SQL Injection, XSS, IDOR identified and remediated pre-production
- ✅ Full-stack observability: Prometheus + Grafana + AWS CloudWatch — zero-downtime deployments

`AWS` `EKS` `Jenkins` `Trivy` `Terraform` `Helm` `OPA Gatekeeper` `Prometheus` `Grafana` `HIPAA`
